# Zoe's diary — public frontend

Website: https://zoe-517.github.io/zoediary/
The root address redirects here, preserving links to diary sections.

GitHub Pages serves the page design and animations. Live public content and visitor interactions use a server gateway in the existing Supabase project. Private content and privileged credentials are never included in this repository.

The author login button opens the existing Google-protected author website. Changes made there use the same cloud database and appear here automatically.
